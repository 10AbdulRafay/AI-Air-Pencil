# AI Air Pencil 🎨

AI Air Pencil is a gesture-based drawing application that uses computer vision and real-time hand tracking to allow users to draw in the air.

## ✨ Features

- 🖐️ Real-time hand tracking
- ✏️ Air drawing
- 🎨 Multiple colors including black
- 📏 Dynamic brush sizing
- 🧹 Eraser
- ↶ Undo
- ↷ Redo
- 💾 Save drawings
- 🖼️ Saved Drawings gallery
- 🗑️ Delete saved drawings
- 🌐 Flask web interface
- 🎯 Gesture-based controls

## 🛠️ Technologies

- Python
- Flask
- OpenCV
- MediaPipe
- NumPy
- HTML
- CSS
- JavaScript
